# Changelog

## 0.1.4 - 2026-11-12

- 识别弱密钥证书及嵌套 TLS 错误，提供中文提示，区分证书不受信任与密钥强度不足。
- 新增默认关闭的 insecureSkipTlsVerifyHosts，仅对 api.osv.dev / api.github.com 跳过证书校验；诊断显示实际目标是否跳过，保留全局开关。
- 补充内网配置说明与主机隔离、代理 TLS 校验回归测试。

## 0.1.3

- 无显式代理时读取 Windows PAC / 静态系统代理；提供检测、禁用与脱敏诊断，失败沿用原访问路径。
- 请求默认超时改为 30 000 ms，新增 timeoutSeconds（10–120 秒）及诊断显示。
- 官方来源逐跳验证 HTTPS 白名单，最多 5 跳。
- Windows 注册表 / PAC 采用模拟测试；仅在 Linux 验证，未宣称真实公司网络或 Windows Desktop 实测。

## 0.1.2 - 2026-11-12

- 合并内网代理 / CA 诊断改动与 main 的 DSH 0.2.2-rc.1 兼容修复（merge intranet proxy/CA diagnostics with main's 0.2.2-rc.1 compatibility）；保留本包两侧已有功能与验证边界。
- 保留代理与 CA 配置、错误分组、诊断命令、最后成功缓存、快照导入导出与离线模式。

## 0.1.1 - 2026-11-11

- 修正 DSH 版本声明为 `>=0.2.1-rc.5 <0.3.0-0`，采用官方包含预发布版本的校验规则，并排除 0.3.0 预发布版本。
- 放宽 DSH peer 范围，显式覆盖 rc.5 / rc.1 的标准 npm semver 安装校验；开发依赖保持原版本。
- 同步锁文件自身版本、打包断言及当前版本标识；兼容性声明不等于逐版本功能验证。

## 0.1.1 (2026-11-11)

- 核对 DSH 0.2.2-rc.1 API 并在 Linux 加载验证；保留原版本范围，Windows / Electron 功能未实测。
- 增加插件级 HTTP 代理、公司 CA、具名网络原因与中文排查提示；默认沿用宿主 fetch。
- 合并重复网络错误，支持网络诊断、缓存快照导入导出及离线模式。


## 0.1.0 — 未发布 / Unreleased

- 核对用户填写的 Kafka / Hadoop / Flink 运行版本，以官方公告给出三态结论，逐条保留来源、UTC+8 抓取时间、范围与限制原文。
- 独立列出 Kafka 官方 suppressions；OSV 仅作第二来源，保留 HTTP 404、范围分歧与 OSV-only 分组。
- 提供无需模型 key 或聊天轮次的 DSH 原生侧栏面板，支持明暗主题、项目标签、版本编辑、刷新、错误及最后成功缓存状态。
- 提供 `/advisory-impact` 命令、六个带前缀的受约束工具，以及可复制/本地保存的中文 Markdown 报告。
- 保存来源响应和时间，遵循 TTL；抓取或解析失败不伪装成空清单。项目文件拒绝路径穿越与符号链接。
- 使用带来源的录制夹具测试；在 DSH 0.2.2-rc.1 实际加载、检查原生界面并完成有限公开 GET 烟测。仅 Git 分支安装，未发布 npm。
