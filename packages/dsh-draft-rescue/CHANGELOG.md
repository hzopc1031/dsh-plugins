## 0.2.0 — 2026-11-10

草稿面板支持按会话 ID 或正文筛选，每页 20 条，点击“预览原文”才挂载该条正文。搜索和分页不修改 localStorage；复制/追加保留原文。追加使用最新输入状态的 draftRev 和胶囊坐标，由宿主 insertText 做 revision guard，不使用 setDraft 覆盖现有输入。会话切换关闭面板并清理预览，迟到的剪贴板结果不回填新面板。仍需枚举并读取当前源中的草稿，分页只减少 DOM/正文渲染开销。列表只显示会话列表或当前会话投影中的可靠标题和工作区，读不到则标为“未知”，不用 displayTitle（它会回退到 id 或目录名）。可按标题或工作区筛选。当前会话条目带“当前会话草稿”标记；面板顶部写明追加目标会话。

- 新版本尚未 npm publish；预构建 lib、独立 lockfile 与回归测试同步。
- 验证范围为 rc.5 运行时与 headless/jsdom；Electron 人工验收仍待执行。
