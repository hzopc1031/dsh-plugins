## 0.1.1 — 2026-11-10

相对链接改用 rc.5 useProjection("workingDirectory") 的宿主计算结果，不使用会话列表的初始 cwd；投影缺失/null 时保留路径未知的降级，不猜测当前目录。目录、会话或回答变化会清空已展开的路径，避免继续复制旧解析结果。相对链接只能按当前有效目录解释，不能反推旧回答生成时的目录；历史回答请核对原始绝对链接。

- 新版本尚未 npm publish；预构建 lib、独立 lockfile 与回归测试同步。
- 验证范围为 rc.5 运行时与 headless/jsdom；Electron 人工验收仍待执行。
