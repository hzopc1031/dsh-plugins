## 0.2.0 — 2026-11-10

会话标题栏新增“插件组合检查”入口（conversation.session.header.actions list slot）。用表单输入两个包名/精确版本、桌面版本、机器、工作区及配置基线，再逐项执行人工操作；结果默认受阻、证据为空，必须人工填写。下一步只读取尚未记录的步骤，record 后继续；受阻/不适用不算通过。保留原 50 步、JSON 命令、重录、snapshot/compare。/combo-lab next <ID> 返回只读下一步数据。不会安装/启停插件、操作桌面或自动认定通过。存档使用 workingDirectory.get(session)，服务缺失回退 header.cwd；/cd 不迁移旧档案。成功的人工命令结果会写明当前执行目录或回退的 header.cwd。计划可选择检查模板（input / sidebar / session-menu / commands / tools-and-panels），默认仍是完整 50 步矩阵；无 template 字段的旧存档按完整矩阵重建。模板或模板版本不同时升级对照不可比。引导面板列出失败与受阻项，并可跳回指定步骤重录。

- 新版本尚未 npm publish；预构建 lib、独立 lockfile 与回归测试同步。
- 验证范围为 rc.5 运行时与 headless/jsdom；Electron 人工验收仍待执行。
